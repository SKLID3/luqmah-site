# موقع لقمة وذوق

واجهة منيو عربية متجاوبة لمشروع لقمة وذوق في شرورة. اختر الأطباق من بطاقاتها المصورة، وحدد الكميات، ثم راجع طلبك وأرسله برسالة واحدة عبر واتساب.

## تشغيل الموقع محليًا

من PowerShell داخل مجلد المشروع:

```powershell
python -m http.server 3000 --bind 127.0.0.1 -d .\public
```

افتح `http://127.0.0.1:3000/`. لا يحتاج الموقع إلى تثبيت حزم أو خادم قاعدة بيانات.

## ملفات الموقع

- `public/index.html`: الصفحة العربية وأقسام المنيو وبطاقات الأطباق والسلة.
- `public/styles.css`: الهوية البصرية والبطاقات والتخطيط المتجاوب.
- `public/app.js`: التصفية والسلة وتخزين الاختيارات محليًا وتكوين رسالة واتساب.
- `public/assets/products/`: صورة مستقلة لكل صنف في المنيو.
- `public/assets/logo-web.jpg`: شعار لقمة وذوق.

تُحفظ السلة على جهاز المتصفح، ويمكن مراجعة الكميات أو حذف صنف قبل فتح واتساب. تُملأ رسالة واحدة بأسماء الأصناف والكميات؛ يراجعها المستخدم ويرسلها يدويًا. لا يعرض الموقع أسعارًا أو مجموعًا ماليًا.
